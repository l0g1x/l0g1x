- Started in **robotics and autonomous systems** -- built ROS drivers, LIDAR localization, and simulation environments with the [Chicago Engineering Design Team](https://github.com/chicagoedt)
- Published companion code for Springer's *ROS: The Complete Reference* textbook
- Worked across the stack from **embedded C++** to **stereo vision pipelines** to **full-stack web applications**
- Now focused on **agent orchestration and context engineering** -- building tooling that helps AI agents coordinate on complex codebases
- Arctic Code Vault Contributor
